# Blogicum

Учебный проект: блог с публикациями, комментариями и профилями пользователей.

## Стек

- Python 3.12
- Django 3.2.16
- SQLite
- django-bootstrap5

## Запуск

1. Клонировать репозиторий.
2. Установить зависимости: `pip install -r requirements.txt`.
3. Применить миграции: `python blogicum/manage.py migrate`.
4. Запустить сервер: `python blogicum/manage.py runserver`.
